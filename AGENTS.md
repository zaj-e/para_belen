# Collaboration preferences

The owner wants to discuss ideas freely without overwriting parts of the game they like.

- Treat suggestions, brainstorming, questions, and requests for an opinion as discussion only. Do not edit or deploy in response to those alone.
- When the owner explicitly asks to implement a change, modify only the requested scope. Preserve unrelated artwork, behavior, wording, styling, and existing user edits.
- Do not publish or deploy merely because a local change was implemented. Wait for an explicit deployment request.
- Keep changes reviewable through version control. Do not reset or overwrite unrelated work.
- Explain the intended scope before making authorized changes, and summarize what changed afterward.
- Keep this project independently runnable and deployable. It is a static site whose editable source lives in dist/.
